# Brain Tumor Segmentation Using 3D Deep Learning

### 3D Densely Connected CNN with Multi-Scale Receptive Fields and Hybrid Loss for Brain Tumor Segmentation

This repository contains the implementation and experimental work associated with my research on **3D brain tumor segmentation using deep learning**.

The project focuses on developing an automated segmentation approach capable of identifying and delineating brain tumor regions from medical imaging data. The proposed framework combines **3D densely connected convolutional neural networks, multi-scale receptive fields, and a hybrid loss function** to improve the quality and robustness of tumor segmentation.

---

## 📌 Research Overview

Accurate brain tumor segmentation is an important task in medical image analysis and can support clinical decision-making, treatment planning, and quantitative analysis.

In this work, a 3D deep learning architecture is investigated to capture both local and contextual information from volumetric medical images.

The main components of the proposed approach include:

* **3D Densely Connected CNN architecture**
* **Multi-scale receptive fields** for capturing features at different spatial scales
* **Hybrid loss function** to address the challenges of medical image segmentation
* End-to-end deep learning-based tumor segmentation

---

## 🧠 Methodology

The proposed framework is designed to learn discriminative volumetric features from 3D medical images and generate accurate tumor segmentation masks.

The overall workflow consists of:

**Medical Images → Preprocessing → 3D Feature Extraction → Multi-Scale Representation → Tumor Segmentation → Evaluation**

---

## 📊 Experimental Results

The model is evaluated using standard medical image segmentation metrics, including:

* Dice Similarity Coefficient (DSC)
* Intersection over Union (IoU)
* Precision
* Recall
* Sensitivity
* Specificity

Detailed experimental results and comparisons are provided in the accompanying research work.
